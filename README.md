# Clear Maker 2C

英単語テストの問題を画面に表示し、紙に書いた答案をスマートフォンで撮影してAI採点するオンライン生徒用Webアプリです。静的画面はGitHub Pages、採点と進捗保存はGoogle Apps Scriptで動作します。

## 主な機能

- TARGET 1800のNo.1〜1800から開始番号・終了番号を指定
- 5 / 10 / 20 / 30問、ランダムまたは番号順で出題
- 「20題ずつチャレンジ」では、20題中18題以上正解するまで次の20題をロック
- クリア済みの任意の回を選び、進行位置を変えずに復習テストを実施
- 現在の生徒画面は「20題ずつチャレンジ」専用。ランダム／番号順の内部処理は将来の再表示用に保持
- 20題チャレンジの進行位置を生徒番号ごとに端末へ保存
- TARGET 1800のクリア進捗率に応じて7段階の称号（ビギナー / ノービス / ルーキー / スペシャリスト / エキスパート / プロフェッショナル / マスター 👑）を表示
- 合格時と次回起動時に、進捗だけをGAS経由でGoogleスプレッドシートの「英単語進捗」へ送信
- ブラウザに保存した端末IDごとに進捗を区別し、同じ端末では続きから再開
- 「英単語進捗履歴」を使った教師用カレンダー・一覧ダッシュボード
- 元データにある各単語5問、合計9000問から問題を選択
- カメラ撮影と端末内画像の追加、複数画像の採点
- 手書き答案の番号・綴りをGeminiで読み取り、90%以上で合格判定
- 結果画像の保存
- 直近50件の採点履歴をブラウザのローカルストレージへ保存
- PWA対応

## ローカル確認

試作中は `start-local.bat` をダブルクリックしてください。ローカルサーバーが起動し、ブラウザで `http://127.0.0.1:8765/index.html` が開きます。終了するときは、起動した黒い画面で `Ctrl+C` を押します。

手動で起動する場合は次のコマンドを使います。

```powershell
python -m http.server 8765
```

ブラウザで `http://127.0.0.1:8765/index.html` を開いてください。カメラはHTTPSまたはlocalhostでのみ利用できます。

ローカル試作では、このフォルダ内の `vocabulary-question.json` と `vocabulary-data.js` を参照します。GitHubへpushしない限り、オンライン版には反映されません。

## 採点サーバー

現在の `student.js` は、Clear Maker 2Bで使用していたGAS WebアプリURLを採点中継として利用します。GASのスクリプトプロパティに生徒アプリ用Gemini APIキーが設定されている必要があります。

`backend_GAS_spreadsheet.gs` を更新してWebアプリを再デプロイすると、同じスプレッドシート内に「英単語進捗」シートが自動作成されます。生徒番号、氏名、クリア済み番号、次の範囲、称号、最終更新が生徒ごとに1行で更新されます。

別のGASへ切り替える場合は、`student.js` 冒頭の `GAS_API_URL` を新しいWebアプリURLへ変更します。答案画像、今回の問題文、正答語は採点時にGAS経由でGemini APIへ送信されます。採点履歴自体は現状サーバー送信せず、使用端末内だけに保存します。

## 教材データの管理と配信（GitHub非公開）

本アプリでは、教材データ（1,800語・9,000問）をGitHub上に公開せず、**GASバックエンドから安全に配信** します。

1. **GAS側での保持**: `vocabulary_data_code.gs` を採点用GASプロジェクト内にスクリプトファイルとして追加します。
2. **初回読み込み**: 生徒アプリ起動時、GAS API (`action: "getVocabularyData"`) を呼び出して暗号化通信で問題データを取得します。
3. **端末キャッシュ（高速・オフライン起動）**: 一度取得した問題データはブラウザのローカルストレージへ保存されるため、2回目以降は通信不要・待ち時間ゼロで起動し、PWAとしてオフラインでも動作します。

```json
{
  "items": {
    "target1800-0001": {
      "word_id": "target1800-0001",
      "word": "the",
      "questions": [
        { "id": "...", "question_text": "..." }
      ]
    }
  }
}
```

オブジェクト内の並び順がTARGET番号として使われるため、No.1から順番に格納してください。

## 生徒の登録解除・削除について

### 1. 管理者側（スプレッドシート）での操作
- **進捗一覧・ダッシュボードから除外する場合**:
  - スプレッドシートの「英単語進捗」シートから該当生徒の行を削除します。
- **個別ダッシュボードURLへのアクセスを停止する場合**:
  - 「公開トークン」シートの該当生徒行で「有効」列（D列）を `FALSE` に変更します（トークン自体を削除しても構いません）。

### 2. 生徒の端末（ブラウザ）側での初期化・変更
- 画面右上の **「⚙（設定）」** を開きます。
- **別の生徒として引き継ぐ場合**: 新しい「生徒番号」と「氏名」を入力して「登録する」を押します。
- **端末内のデータを完全に消去・最初からやり直す場合**: **「端末の登録・進捗を初期化」** ボタンを押すと、生徒情報・学習進捗・採点履歴・苦手リストがすべてクリアされ、初期状態に戻ります。

## カメラ利用許可のトラブルシューティング
生徒の端末（特にiPad / iPhone）でカメラが起動しない場合：
- **原因**: 初回アクセス時にカメラ利用許可ダイアログを拒否または無視したため、ブラウザ側で禁止設定になっている。
- **解除方法**:
  - **iPad / iPhone (Safari)**: アドレスバー左端の「ぁあ(AA)」をタップ ➔「Webサイトの設定」 ➔「カメラ」を【許可】にする（または端末の【設定】➔【Safari】➔【カメラ】）。
  - **Android / PC (Chrome)**: アドレスバー左端の鍵アイコン ➔「権限」 ➔「カメラ」を【許可】にする。
  - ※カメラを起動せず「写真ライブラリ（アルバム）」から写真を選んで提出することも可能です。
